Put your own product photos here, named <product-slug>.jpg (e.g. bath-soap.jpg),
then run: npm run shop-photos && npm run build

MORE PHOTOS FOR ONE PRODUCT
  Main photo:   bath-soap.jpg
  Extra photos: bath-soap-2.jpg, bath-soap-3.jpg, bath-soap-4.jpg ...
  The product page shows them as a swipeable gallery, in number order.

YOUR ORIGINAL FILES
  When you add photos with the editor, it saves its own copy here under the product's web name.
  Your original files can be kept in shop-photos/_originals/ (not used by the website, not uploaded to GitHub).
